Git, Github, venv and uvicorn
To initially get and work with the project (once set up on github) run the command:
Git clone link to the repo


When you have this open the project folder in vscode(the folder should be in) documents/github/name of project
make a terminal by going to View, then Terminal or Control/Cmd + ‘ 
Then run the command:
python3 -m venv venv
Then on Mac/Linux run:
source venv/bin/activate
Or on Windows run:
venv\Scripts\Activate.ps1
Then run: 
pip install -r requirements.txt
Now deactivate the venv by running:
Deactivate


When adding a new feature to the project run MAKE SURE YOU DEACTIVATE THE VENV:
git branch name of feature
Git switch name of feature


After making a function or change to the code commit the change by running:
Git add name of file you have changed
Git commit -m ‘short description of the the change you have made e.g added subtraction function’


When you have finished or made significant progress and you want others to use, ensuring everything is committed, push you change to the repo by running:
Git push origin name of branch


On the repo website there should be an option to make a pull request. Complete this and there should be another option to merge the pull request. Sort out any merge conflicts and then merge your changes to the main branch. 


To then get these changes your local project, run:
Git pull origin main


This should be all you have to do on git and github
Do not use git commands inside the venv
Try not to edit the same file as others to avoid merge conflicts
Run:
Git status to see staged files to be committed
Git log to see previous commits
